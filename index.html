古文

古文の基礎は、大きく「単語」と「文法」の2つに分かれます。本書ではまず文法から作っています。文法は「型」の学問なので、先に型を身につけると、単語を覚えるときにも文の見通しがよくなります。

なぜ文法から始めるのか

  1. 文法の項目は数が限られていて、全体像をつかみやすい
  2. 活用が分かると、辞書が引けるようになり、単語学習が速くなる
  3. 助動詞が分かると、文の意味の「骨格」が読めるようになる

古典文法 ― 単元一覧

学習順に並んでいます。各単元は「概要 → 解説 → 実用例 → 注意点」の4部を小節に分けたスモールステップ式で、1画面ずつ進みます。例文は層を1つずつ開いて読み、ミニ確認（正誤判定つき）で確かめ、単元の最後に「思い出す形式」のまとめが置かれています。初学者は上から順に進むのがおすすめですが、すべての単元に最初からアクセスできます。

漢文

漢文は、中国で書かれた文章を、日本語の語順に直して読む（訓読）科目です。いきなり原文に触れると拒否感を持ちやすいので、本書では導入の段差を極限まで低くし、「漢文と日本語の違いは語順が中心」という確認から始めます。分野は3つです。まずは「訓読・句法」の単元1から進んでください。

漢文の学び方

  1. 「訓読・句法」を単元1から順に進むのが基本です（全単元に最初からアクセスできます）
  2. 例文は、原文 → 注釈 → 読む順 → 書き下し → 訳 → 理由、の層を1タップずつ開いて読みます
  3. まだ正式に習っていない読み方・送り仮名は、習うまで毎回併記します。現代では使わない読みの語には、読みと意味の両方を付けます
  4. 進捗のチェック（✓）は、このページを開いている間だけ保持されます

訓読・句法 ― 単元一覧

句法・句形の単元は、句形ごとではなく意味の性質ごとに立てています。同じ意味を表す句形が1か所に集まるので、単元の中で使い分けを比べられます。各単元は小節（句形ごと）に分かれ、小節ごとにスモールステップで学びます。

重要漢字

漢文の漢字は、1字が文法の働きを持つことが多いのが特徴です。ここでは訓読・句法の単元の順序に合わせて、働きのグループごとに整理しました。「訓読み」欄には書き下しで使う読みを、「例」には白文と書き下し・訳を付けています。現代では使わない読みの語には意味も添えています。

漢詩

漢詩は、決まった字数と音の約束の中で作られる中国の詩です。約束が決まっているからこそ、型を知れば初見の詩でも読み解けます。まず形式としくみを押さえ、最後に李白の「静夜思」を全句読みます。

形

形式 ― 字数と句の数で決まる

漢詩の形式は、1句の字数と全体の句数の組み合わせで決まります。1句は5字（五言）か7字（七言）が基本で、2句で1つのまとまり（聯）を作ります。

漢詩の主な形式
形式句数字数（五言／七言）特徴
絶句4句20字／28字最も短い形式。起承転結の構成が基本
律詩8句40字／56字中間の2聯（第2・第3聯）に対句が必須
排律10句以上―律詩を長くした形式。試験では参考程度
古詩制限なし―近体詩の約束に縛られない、古い形式の総称

絶句と律詩を合わせて近体詩といいます。近体詩には、次に説明する押韻・対句・平仄（ひょうそく）の約束があります。

韻

しくみ ― 押韻・対句・平仄・起承転結

1. 押韻（おういん）

決まった句の最後の字に、同じ響きの韻（いん）の字をそろえる約束です。絶句では第1句・第2句・第4句の句末で韻を踏むのが基本（第1句は踏まない場合もあります）で、第3句の句末は韻を踏みません。韻は中国語の発音での響きの一致なので、日本語の音読みでも響きが似る字が選ばれることが多いです。

2. 対句（ついく）

2句を1組にして、字数・品詞・意味の構成をそろえる技法です。たとえば「山」に対して「水」、「高い」に対して「深い」のように、対になる言葉を並べます。律詩では中間の2聯が対句でなければなりません。絶句でも対句が使われることがあります。

3. 平仄（ひょうそく）

漢字の音には、平らかな音（平声）と、上がったり詰まったりする音（仄声）があります。近体詩では句の中の字の平仄の並びに規則があり、これを平仄式といいます。細かい式の暗記までは不要ですが、「音の並びにも約束がある」ことと、平仄が合わない字をわざと置くことはできない、という原則を押さえてください。

4. 起承転結（きしょうてんけつ）

絶句4句の役割分担です。起句で場面を起こし、承句で受けて深め、転句で視点や場面を転じ、結句で気持ちに落として締めます。転句で何が「転じた」かを見つけることが、絶句を読む最大の手がかりです。

詩

実例 ― 李白「静夜思」

唐の詩人・李白の五言絶句です。故郷を離れて旅の空にある人が、月を見て故郷を思う気持ちを詠みました。まず白文を縦書きで示します。

床前明月光、疑是地上霜。挙頭望明月、低頭思故郷。
李白「静夜思」― 五言絶句

書き下し文

床前（しやうぜん）明月の光、疑ふらくは是れ地上の霜かと。頭を挙げて明月を望み、頭を低（た）れて故郷を思ふ。

現代語訳

寝台の前に、明るい月の光が差している。まるで地面に降りた霜ではないかと思った。頭を上げて明るい月を眺め、頭をうつむけて故郷のことを思う。

句ごとの注釈

  • 第1句「床前明月光」（起）：床は寝台。寝台の前に月の光が差している、という場面の提示です。
  • 第2句「疑是地上霜」（承）：疑ふらくは＝「〜ではないかと疑う」。月の光を霜に見まがえた、と受けて深めます。
  • 第3句「挙頭望明月」（転）：頭を上げて月を見る、と動作が転じます。光（地上）から月（空）へ視線が上がるのが転換点です。
  • 第4句「低頭思故郷」（結）：頭を低（た）れる＝うつむく。第3句の「挙頭」と「低頭」が対句になっていて、月を見上げた反動で故郷への思いに沈む締めです。

形式の確認

  • 押韻：第1句末「光」・第2句末「霜」・第4句末「郷」が、中国語では同じ「ang」の響きの韻を踏んでいます（音読みでも「コウ・ソウ・キョウ」と響きがそろいます）。第3句末「月」は韻を踏みません。
  • 対句：「挙頭」と「低頭」（上げる／下げる）、「望明月」と「思故郷」（見る／思う）が対になっています。
  • 起承転結：光を見る（起）→ 霜かと疑う（承）→ 月を見上げる（転）→ 故郷を思う（結）。
読

漢詩を読む手順

  1. 形式を確認する：字数（五言／七言）と句数（絶句／律詩）を見る
  2. 韻を踏む字を拾う：句末の字を見て、場面の区切りをつかむ
  3. 起承転結で場面を追う：特に転句で何が変わったかを探す
  4. 書き下して訳す：訓読・句法で学んだ返り点と句形の道具が、そのまま使えます

漢詩は、訓読の学習の「仕上げの読み物」でもあります。句法の単元を終えたら、もう一度この詩を支えなしで読んでみてください。
